# SmartReview LP

SmartReview - 習い事教室専用 口コミ集客ツール ランディングページ

## 概要

習い事教室向けの口コミ集客ツール「SmartReview」のランディングページです。

## 機能

- 質問項目カスタマイズ
- スマート遷移設定
- リアルタイム集計ダッシュボード
- 口コミ自動収集・分析

## 技術スタック

- HTML5
- CSS3 (アニメーション)
- JavaScript (スクロール連動)
- レスポンシブデザイン

## ファイル構成

- `index.html` - メインのランディングページ
- `lp_structure.json` - ページ構造のJSON仕様
- `README_lp_structure.md` - 構造仕様の説明

## 開発

ローカルで確認する場合：

```bash
# ローカルサーバーを起動
python -m http.server 8000
# または
npx serve .
```

ブラウザで `http://localhost:8000` にアクセスしてください。

## デプロイ

Vercel、Netlify、GitHub Pages等の静的サイトホスティングサービスでデプロイ可能です。
